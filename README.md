# 💅 Mon Atelier Nail Art 🎀

Application web personnelle (PWA) de Nail Art & atelier créatif privé.
Carnet de manucure, studio de création, visualiseur de main, inventaire de gels UV,
chrono UV et Story Cards partageables.

Ce n'est **pas** un site commercial : c'est un carnet personnel privé.

## Contenu
- `index.html` — l'application complète, autonome (un seul fichier).
- `supabase/schema.sql` — schéma de la base Supabase (synchronisation privée, RLS par compte).

## Utilisation
Ouvrir `index.html` dans un navigateur mobile, puis « Ajouter à l'écran d'accueil »
pour l'installer comme une vraie application.

## Technique
HTML5 · Tailwind (CDN) · Lucide Icons · Canvas-Confetti · html2canvas · Supabase (synchro) ·
LocalStorage (cache hors-ligne).

Dépôt **privé**.
